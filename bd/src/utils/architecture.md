# Архитектура

## Поток данных
1. **Scan** — рекурсивный обход папки
2. **Process** — извлечение текста через соответствующий процессор
3. **Chunk** — разбиение на чанки (sentence-based)
4. **Encode** — векторизация на GPU (2x V100)
5. **Store** — сохранение в FAISS + метаданные в JSON
6. **Search** — семантический поиск по запросу

## GPU стратегия
- `sentence-transformers` автоматически использует все видимые GPU
- `faiss-gpu` для быстрого поиска
- Batch size 64 оптимален для V100 16GB

## Расширение
- Добавить новый формат: создать класс в `src/processors/` и зарегистрировать в `registry.py`
- Сменить модель: изменить `vectorization.model` в `config/default.yaml`
